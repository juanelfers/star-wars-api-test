# Star Wars Explorer

> Browse and search the Star Wars universe, powered by the public
> [SWAPI](https://swapi.dev/). Built with Next.js 14, NextUI and Framer Motion.

**🔗 Live demo: [star-wars-api-test.vercel.app](https://star-wars-api-test.vercel.app/)**

## Features

- **Search** characters by name
- **Animated character cards** powered by Framer Motion
- **Loading & streaming states** using the Next.js App Router
- A small **typewriter** effect for the headings

## Tech stack

- **[Next.js 14](https://nextjs.org/)** (App Router) + **TypeScript**
- **[NextUI](https://nextui.org/)** components + **Tailwind CSS**
- **[Framer Motion](https://www.framer.com/motion/)** animations
- Data from **[SWAPI](https://swapi.dev/)**

## Getting started

```sh
npm install
npm run dev      # http://localhost:3000
```
